# Vertex AI — Employee Management Platform

An AI-based employee management platform built for the Infosys Springboard project.

## Features
- **Dashboard** — team-wide stats and AI-flagged concerns at a glance
- **Employees** — searchable, sortable directory with a live AI performance score (attendance + task completion)
- **Attendance** — mark daily attendance, which feeds directly into the AI model
- **AI Insights** — auto-generated flags for retention risk, downward trends, and top-performing departments
- Light/dark theme, employee detail view, department performance chart

## Tech
Single-file HTML/CSS/JS app — no build step, no backend. Data persists in the browser via `localStorage`.

## Run it
Just open `index.html` in a browser, or enable GitHub Pages on this repo (Settings → Pages → deploy from `main` branch) to get a live link.
